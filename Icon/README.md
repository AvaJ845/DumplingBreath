# Icon — Dumpling Breath

The app ships a **deterministic, code-drawn** app icon generated by
`RenderIcon.swift`. This is the working v1 the ROAST and the App Icon Brief
call for — brief-compliant, version-controlled, good enough to go to
TestFlight — **not** the final commissioned art.

## Run it

```sh
swift Icon/RenderIcon.swift
```

Pure Core Graphics, no randomness, no network, no external assets. Every run
produces byte-for-byte identical PNGs. It resolves paths relative to its own
location, so the working directory does not matter.

## What it produces

| File | Slot |
|---|---|
| `App/Assets.xcassets/AppIcon.appiconset/icon-1024.png` | iOS / iPad, **shipped default** (faceless) |
| `App/Assets.xcassets/AppIcon.appiconset/icon-1024-dark.png` | iOS 18 dark appearance |
| `App/Assets.xcassets/AppIcon.appiconset/icon-1024-tinted.png` | iOS 18 tinted appearance (flat grayscale silhouette) |
| `Icon/icon-1024-dots.png` | **A/B only — not wired, and kept OUT of the appiconset** (an unreferenced file there trips an "unassigned child" warning). Same icon with two subliminal closed-eye arcs, for a human to compare against the faceless default |
| `Watch/Assets.xcassets/AppIcon.appiconset/icon-1024.png` | watchOS (dumpling larger in frame, ground simpler so it survives the circular crop) |
| `docs/icon-preview.png` | contact sheet: 1024 / 180 / 120 / 87 / 60 / 40 / 29 px + a 40 px grayscale, for the "reads at 40 pt" and "legible in grayscale" tests |

All PNGs are 1024×1024, sRGB, 8-bit, **opaque (no alpha)** — as required for
App Store icons. Xcode 16's asset catalog generates every smaller rendition
from the single 1024 (the spec sheet's multi-size table is legacy — ignore it).

Both `Contents.json` files already carry the `filename` keys. The faceless
default is shipped per `docs/APP_ICON_BRIEF.md:52` and `docs/ICON_ROAST.md`.
To A/B the closed-eye version, copy `Icon/icon-1024-dots.png` over
`App/Assets.xcassets/AppIcon.appiconset/icon-1024.png` and rebuild.

## The design (per APP_ICON_BRIEF.md + ICON_ROAST.md + the concept-2 refinement)

- **One over-stuffed dumpling, centred**, ~60% of the canvas width, generous
  air around it. Plump super-ellipse (`n = 2.2`), gently top-lit, matte, with a
  soft contact shadow and a small gathered pleat-fan at the crown.
- **The squeeze** — two soft thumb-tips press the cheeks inward at the widest
  point. Each cheek visibly *muffin-tops* over its thumb (the body is painted,
  then the thumbs, then the body again over them). No hands, no fingers, no
  nails — just the rounded pad and the dent.
- **No face** by default. `icon-1024-dots.png` adds two subliminal closed-eye
  arcs (no mouth, no blush) for the A/B.
- **Warm** off-white body: `#FCF5E8` → `#EEDCC2` (the in-app dumpling colours),
  thumb pads a warmer tan (`#E7C9A7` → `#CAA77F`).
- **Warm neutral ground**: a soft low-saturation radial around `#8D755C`
  (centre `#967E64`, edge `#77605C`… i.e. a warm clay). Not white, not a loud
  gradient, not purple/blue. Dark appearance: deep warm charcoal `#211B16`.
- **Grayscale**: the dumpling body sits at luminance ≈ 0.86 against a ground of
  ≈ 0.16–0.19 — a contrast of ~3.8–4.4 : 1, above the brief's 3 : 1 bar. The
  generator prints this check on every run.
- **40 pt**: the thumb pads and pleats melt away; what remains is a plump
  rounded form with two softly pinched cheeks. See `docs/icon-preview.png`.

Concept sheets `docs/icon-concept-1-bowl.png` / `docs/icon-concept-2-squeeze.png`
are **mood reference only** — the warm, squeezable feeling. The Fellows ruled
Cut on the face, the bowl, the broth, the breath swirls, the literal hands and
the purple/blue gradient. None of those appear here.

## Swapping in the commissioned final art

When the illustrator delivers, you do **not** need to run the generator again.
Just replace the PNGs in place, keeping the same filenames and constraints
(1024×1024, sRGB, opaque, no rounded corners, no alpha):

1. `App/Assets.xcassets/AppIcon.appiconset/icon-1024.png` — iOS master
2. `App/Assets.xcassets/AppIcon.appiconset/icon-1024-dark.png` — dark master
3. `App/Assets.xcassets/AppIcon.appiconset/icon-1024-tinted.png` — a flat
   grayscale silhouette of the dumpling form (`docs/APP_ICON_BRIEF.md:73-75`)
4. `Watch/Assets.xcassets/AppIcon.appiconset/icon-1024.png` — watch master

The `Contents.json` files and `project.yml`
(`ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`) already point at these names,
so no further wiring is needed. Keep `RenderIcon.swift` around — it is the
fallback and the record of the v1 that shipped.

If you keep using the generator, tune the constants at the top of
`renderIcon(...)` / `renderTinted(...)` (`bodyFraction`, `dentDepth`,
`dentAngle`, `expo`) and the `standardPalette` / `darkPalette` structs.
